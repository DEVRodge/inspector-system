# 将《用户操作手册》导出为 PDF

手册主文件：**[光伏厂区设备巡检系统-用户操作手册.html](./光伏厂区设备巡检系统-用户操作手册.html)**（与本文同目录）

配套插图：**[manual-cover.png](./manual-cover.png)**（封面用图，已放在 `docs/` 下）

## 推荐方式：Chrome / Edge 打印为 PDF

1. 用 **Chrome** 或 **Edge** 打开上述 **HTML** 文件（双击或通过「文件 → 打开文件」）。
2. 按 **`Ctrl + P`**（Mac：**`⌘ + P`**）打开打印对话框。
3. **目标打印机** 选择 **「另存为 PDF」** / **「Microsoft Print to PDF」**。
4. 建议设置：
   - **边距**：默认或「最小」
   - **背景图形**：**开启**（以保留封面与彩色示意图）
   - **页眉页脚**：可按需关闭（界面更干净）
5. 点击 **保存**，即可得到 **PDF**。

> 若手册中留有「建议截图」虚线框，可在系统真实环境截屏后，用 Word / WPS 打开 HTML 再导出 PDF，或把截图插入 PDF 编辑工具中替换占位区域。

## 可选：使用 Pandoc（需本地安装）

若已安装 [Pandoc](https://pandoc.org/)，可将 Markdown 版（若有）转换为 PDF，需额外配置 LaTeX 或引擎；当前以 **HTML 打印** 为主流程，兼容性最好。
