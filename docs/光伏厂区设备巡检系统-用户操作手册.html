1. 系统简介与登录

1.1 系统能做什么

本系统用于光伏厂区设备巡检的统筹管理：维护设备台账、配置巡检模板与计划任务、查看巡检记录与现场照片、处理巡检异常，并通过统计报表掌握执行情况。

1.2 如何登录

  1. 在浏览器地址栏输入管理员提供的系统访问地址（由单位 IT 或项目负责人下发）。
  2. 若未登录，会自动进入「后台登录」页。
  3. 输入账号与密码，点击登录。
  4. 登录成功后进入工作台；左侧为功能菜单，右上角可查看个人信息与消息。
【建议截图】登录页全貌：左侧品牌区 + 右侧账号密码表单
安全提示：勿向他人泄露账号密码；使用完毕可在个人菜单中退出登录（若界面提供）。

2. 界面总览与菜单

登录后典型布局为：顶栏（系统标题、消息、设置入口等）、左侧菜单、主内容区。部分菜单项由管理员在后台授权，若您看不到某项功能，请联系管理员开通权限。

2.1 功能模块一览

模块用途简述
工作台总览设备数、今日/本月任务与完成率、待处理异常等
设备台账设备档案的查询、新增、编辑、删除；支持二维码预览与下载
巡检模板按设备类型配置巡检表单结构（巡检项树）
计划任务创建周期性或一次性巡检任务，关联设备与模板
巡检记录查询历史巡检结果，查看明细与照片
异常管理查看异常、指派处理人、填写处理结果与附件
统计报表图表化统计与分析（以实际开放图表为准）
系统管理用户、角色、菜单等（需权限；无权限时无法进入）

3. 工作台

进入系统后默认打开工作台，用于快速了解当前运行态势。

3.1 常见指标卡片

  • 设备总数及本月新增设备数量
  • 今日应执行任务与已完成数量
  • 待处理异常及待指派数量
  • 本月完成率及本月已完成 / 总任务数

页面中可能还包含今日 / 本月任务完成率的环形或条形展示，数据均来自服务端实时统计。

【建议截图】工作台指标卡片与完成率图表区域
若加载失败，请检查网络或稍后刷新页面；仍无法显示请联系管理员确认接口服务。

4. 设备台账

4.1 查询与筛选

在设备台账中可通过关键字、设备类型、运行状态等条件筛选（以页面实际筛选项为准），支持分页浏览。

4.2 新增与编辑设备

  1. 点击新增或某行的编辑，打开表单。
  2. 填写设备编码、名称、类型、位置等信息；设备类型一般来自数据字典，请与巡检模板侧的设备类型保持一致。
  3. 运行状态多为运行中 / 维护中 / 停机等固定选项。
  4. 保存后返回列表。

4.3 二维码

在设备行操作中可预览或下载二维码，便于现场扫码关联设备（具体按钮名称以界面为准）。二维码由前端生成，无需单独下载接口。

【建议截图】设备列表 + 二维码弹窗或下载效果

5. 巡检模板

模板定义「某一类设备要检哪些项、如何填写」。一种设备类型通常仅关联一个模板。

5.1 新增模板

  1. 点击新增模板。
  2. 填写模板名称、选择适用设备类型、说明、版本号。
  3. 状态为系统枚举：草稿（DRAFT）与启用中（ENABLED），无需在字典中维护。
  4. 保存后，在模板列表中对该模板进行配置巡检项（树形结构：检查项名称、是否必填、录入方式等）。

5.2 编辑与删除

已存在的模板可编辑基础信息；删除前请确认无关键业务依赖。编辑时若限制修改设备类型，属于系统规则，避免破坏已有数据关联。

【建议截图】新增/编辑模板表单 + 巡检项配置弹窗

6. 计划任务

将巡检工作以任务形式下发到计划周期，并关联设备与模板。

6.1 新建任务

  1. 进入计划任务，点击新建。
  2. 填写任务名称、执行计划（如 Cron 表达式或界面提供的周期配置）、负责团队/负责人等（以表单字段为准）。
  3. 选择关联的设备与适用的巡检模板。
  4. 保存后，任务按计划生成执行实例（具体由后端调度）。

6.2 维护与查看

支持在列表中查看任务概况、编辑或删除（以权限与按钮为准）。

【建议截图】计划任务列表 + 新建/编辑任务表单

7. 巡检记录

记录现场执行后产生的巡检结果汇总，以列表形式查询。

7.1 查询

可按任务名称、设备、巡检人、结果状态（如正常/异常）、日期范围等筛选，点击查询刷新列表。

7.2 详情与照片

点击查看详情进入记录详情页，可查看各设备的巡检项结果、现场照片（多张预览）。照片地址由系统根据文件存储路径解析，若图片无法显示，请联系管理员检查文件服务与网关配置。

【建议截图】巡检记录列表 + 记录详情中的照片网格

8. 异常管理

当巡检判定为异常或业务规则产生异常单时，在此进行跟踪与闭环。

8.1 列表与筛选

支持关键字、状态、时间范围及「仅看我的任务」等筛选（以页面为准）。

8.2 指派与处理

  1. 打开异常详情。
  2. 对待处理单据可指派处理人。
  3. 处理人在处理中状态可填写处理说明、上传附件并提交，进入已关闭等终态（以后端状态机为准）。
【建议截图】异常列表 + 详情页指派/处理区域

9. 统计报表

通过图表展示巡检相关统计（如完成趋势、分布等），具体图表项以后台配置与接口返回为准。支持按时间范围筛选时，请选择合理区间后点击查询或刷新。

【建议截图】统计报表主界面

10. 系统管理与消息

10.1 系统管理

若账号具备权限，侧栏会出现系统管理入口，用于用户、角色、菜单等配置。若无权限访问该路径，系统将提示无权限。

10.2 消息与通知

顶栏消息图标可查看系统通知列表、未读数量；支持标记已读。部分环境会通过 WebSocket 推送新消息，需保证网络可访问后端配置的推送地址。

【建议截图】消息下拉列表或消息中心

11. 常见问题（FAQ）

现象建议处理
无法登录确认账号密码、大小写；联系管理员重置密码或检查账号是否启用。
登录后菜单很少由角色权限控制，联系管理员分配菜单与功能权限。
图片/附件打不开检查是否登录有效；联系管理员检查文件存储与网关（如 /minio 或下载接口）。
收不到实时消息确认网络与防火墙；管理员需检查 WebSocket（wss）与反向代理 Upgrade 配置。
导出 Excel 无反应部分按钮可能尚未对接导出接口，以当前版本为准或联系开发确认。
